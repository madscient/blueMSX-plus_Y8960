# Y8960 対応 — 使い方

このフォークの blueMSX+ は、音源カートリッジ **Y8960** をエミュレートします。

Y8960 のハードウェアは開発中です。エミュレーションは現時点の仕様に沿っており、
**仕様が変われば動作も変わります。** ハードウェアの仕様は
[hra1129/Y8960_Cartridge](https://github.com/hra1129/Y8960_Cartridge) で
開発されています。

## Y8960 の構成

Y8960 は 7 つのブロックでできています。blueMSX+ では**ブロックごとに独立した
デバイス**として、マシン構成に 1 つずつ追加します。

| マシン構成での表示名 | 内容 |
|---|---|
| Y8960 SCC | SCC、バンクメモリ、I/O イネーブラ、メモリマップド I/O。**カートリッジ ROM はここに載せます** |
| Y8960 OPLLEX | YM2413 相当 ×2。チャンネルごとに 4 種類の音色 ROM を切り替えられます |
| Y8960 OPL2EX | YM3812 + ADPCM-B 相当 ×2 |
| Y8960 SSGS | YM2149 相当 ×2。チャンネルごとのパンポット付き |
| Y8960 DCSG | SN76489 相当 ×2 |
| Y8960 MSX-TIMER | 4 本のカウンタと割り込み |
| Y8960 MSX-MIXER | ブロックごとの音量（**ハードウェア側が未実装のため、現状は音に影響しません**） |

## マシン構成に追加する

**ツール → マシン構成編集** を開き、**メモリ** タブの **追加...** で
上の表のタイプを選びます。**カートリッジの形では** 7 つすべてを追加すると
Y8960 一式になります（本体内蔵の形は後述）。

**Y8960 SCC だけは ROM イメージを指定します**（カートリッジ ROM）。
ほかの 6 つは ROM を持ちません。

Y8960 SCC は、マシン構成に追加する代わりに**カートリッジとして挿す**こともできます。
ほかの 6 つをマシン構成に追加しておき、**ファイル → ROMスロット** から ROM イメージを
挿入して、**ROM タイプ** に **Y8960 SCC** を選びます。
**Y8960 SCC はどちらか一方の方法で 1 つだけ**にしてください。

設定ファイル（`config.ini`）を直接編集する場合、`[Slots]` に書く番号は次のとおりです。

| タイプ | 番号 | コマンドラインでの名前 |
|---|---|---|
| Y8960 OPLLEX | 180 | `Y8960OPLLEX` |
| Y8960 OPL2EX | 181 | `Y8960OPL2EX` |
| Y8960 SSGS | 182 | `Y8960SSGS` |
| Y8960 MSX-TIMER | 183 | `Y8960TIMER` |
| Y8960 MSX-MIXER | 184 | `Y8960MIXER` |
| Y8960 SCC | 185 | `Y8960SCC` |
| Y8960 DCSG | 186 | `Y8960DCSG` |

コマンドラインから Y8960 SCC をカートリッジとして挿す例:

```
blueMSX+.exe /machine "<マシン構成名>" /rom1 <ROM ファイル> /romtype1 Y8960SCC
```

## カートリッジとして使う場合と、本体内蔵の場合

Y8960 はカートリッジとして挿す形と、本体に内蔵される形の 2 通りがあります。
**動作が違います。**

| | カートリッジ | 本体内蔵 |
|---|---|---|
| I/O イネーブラ | **有り。** リセット直後はすべて閉じています | **無し。** すべてのブロックが常に応答します |
| メモリマップド I/O | 有り | 無し |
| SSGS | 本体の PSG に重ねて発音します。**読み出しはできません** | **本体の PSG の代わりになります。** 読み書きでき、ジョイスティック・カセット・かな LED が繋がります |

**I/O イネーブラとメモリマップド I/O は Y8960 SCC が持っています。**
Y8960 SCC を**追加しない**マシン構成では、イネーブラもメモリマップド I/O も無くなり、
ほかのブロックはすべて常に応答します。

**本体内蔵の形**にするには、次の 2 つを行います。

1. マシン構成編集の **基盤タイプ** で **MSX2++** を選ぶ。SSGS が本体の PSG になります
2. **Y8960 SCC と Y8960 SSGS は追加しない。** SSGS は本体の PSG として既に
   組み込まれています。ほかのブロックは必要なものを追加します

MSX2++ の VDP は V9968 になる予定ですが、現在のこのフォークでは対応していません。

## I/O とメモリマップド I/O

**カートリッジの場合**、ブロックの I/O ポートは I/O イネーブラを開くまで応答しません。
イネーブラはメモリマップド I/O にあり、BANK1 に ROM バンクが出ているときだけ見えます。
メモリマップド I/O の**トンネル**からは、イネーブラを開かなくても各ブロックに書き込めます。

| ブロック | I/O ポート | イネーブラ | トンネル |
|---|---|---|---|
| OPLLEX 1 | `7Ch` アドレス / `7Dh` データ（書き込みのみ） | `7FF6h` bit 0 | `7FF4h` / `7FF5h` |
| OPLLEX 2 | `7Ah` / `7Bh`（書き込みのみ） | `7FF6h` bit 1 | `7FF2h` / `7FF3h` |
| OPL2EX 1 | `C0h` アドレス・ステータス / `C1h` データ | `7FFFh` bit 0 | `7FEEh` / `7FEFh` |
| OPL2EX 2 | `C2h` / `C3h` | `7FFFh` bit 1 | `7FECh` / `7FEDh` |
| DCSG 1 | `3Eh`（書き込みのみ） | `7FFFh` bit 2 | `7FF1h` |
| DCSG 2 | `3Fh`（書き込みのみ） | `7FFFh` bit 3 | `7FF0h` |
| SSGS | `A0h` レジスタ / `A1h` データ（書き込みのみ） | `7FFFh` bit 4 | `7FEAh` / `7FEBh` |
| MSX-TIMER | `B0h`-`B3h` | `7FFFh` bit 7 | なし |
| MSX-MIXER | `B6h` レジスタ / `B7h` データ（書き込みのみ） | なし | なし |

**トンネルは書き込みのみです。** 閉じているイネーブラの I/O ポートを読むと `FFh` が返ります。

MSX-MIXER のアドレスは暫定です。

### バンクメモリと SCC

| | |
|---|---|
| バンク | 256KB。`#0`-`#15` が ROM、`#16`-`#31` が RAM |
| SCC | BANK1 のバンクレジスタに `3Fh` を書くと、`7800h` に SCC が出ます |
| メモリマップド I/O | `7FE0h`-`7FFFh`。BANK1 に ROM バンクが出ているときだけ見えます |

## ブロックごとの動作

### OPLLEX

YM2413 と同じレジスタに加えて、**`40h`-`48h`**（チャンネル 0-8）の
bit 1-0 で、そのチャンネルが使う音色 ROM を選びます。

| 値 | 音色 |
|---|---|
| 0 | OPLL（YM2413） |
| 1 | OPLL-X（YM2423） |
| 2 | OPLL-P（YMF281） |
| 3 | VRC7 |

ユーザー音色（音色 0）はチャンネルで共通です。バンクを切り替えても変わりません。

プリセット音色は各チップの ROM そのものではなく、互換の音色データです（末尾の「帰属表示」）。
そのため OPLL の音色は、本体の MSX-MUSIC と完全には一致しません。

### OPL2EX

YM3812 のレジスタ配置で、**`E0h`-`F5h` による 4 種類の波形選択**に対応しています
（`01h` の bit 5 で有効になります）。リズム音には波形選択が効きません。

ADPCM-B のサンプル RAM は **256KB を 2 回路で共有**します。

MSX-AUDIO のキーボード端子、13bit DAC、I/O ポートは持ちません。

### SSGS

| アドレス | 内容 |
|---|---|
| `00h`-`1Fh` | 1 系統目 |
| `20h`-`3Fh` | 2 系統目 |

各系統の中で、`00h`-`0Dh` は YM2149 と同じ、`10h`-`12h` はチャンネル A/B/C の
**4bit パンポット**です。2 系統目の `2Fh` の下位 4bit は LED です
（エミュレータでは表示されません）。

パンポットは 8 が中央、値が小さいほど左、大きいほど右です。
**リセット直後は中央です。** パンポットの特性はハードウェアの仕様が
決まっていないため暫定です。

### MSX-MIXER

`B6h` / `B7h` に書いた値は保持されますが、**現状は音に影響しません。**
ハードウェア側のレジスタ仕様が決まっていないためです。

## 音量の調整

**Y8960 の音量・パン・有効/無効は、ミキサー画面に出ません。**
すべてのブロックの音がまとめて 1 つのチャンネルに入っています。
変更するには、エミュレータを終了してから設定ファイル `bluemsx.ini` を編集します。

```
sound.mixerChannel.MIXER_CHANNEL_Y8960.enable=yes
sound.mixerChannel.MIXER_CHANNEL_Y8960.pan=50
sound.mixerChannel.MIXER_CHANNEL_Y8960.volume=90
```

基盤タイプが MSX2++ の場合、本体の PSG の音もこのチャンネルに入ります。

## ファームウェア

Y8960 を駆動する拡張 BASIC と BIOS が
[madscient/MsxSoundSuiteExtension](https://github.com/madscient/MsxSoundSuiteExtension)
で開発されています。**本エミュレータには同梱していません。**
入手方法と利用条件はそちらを参照してください。

## 動作の確認が済んでいない機能

次の機能は実装されていますが、動作の確認が済んでいません。

- MSX-TIMER の割り込みが CPU に届くこと
- BANK2 / BANK3 に SCC を出すこと
- SCC と DCSG の音
- Y8960 SCC を追加しないマシン構成で、ほかのブロックが常に応答すること
- ステートセーブとロード
- ファームウェア（MsxSoundSuiteExtension）での動作
