# Y8960 対応 — 使い方

このフォークの blueMSX+ は、音源カートリッジ **Y8960** をエミュレートします。

Y8960 のハードウェアは開発中です。エミュレーションは現時点の仕様に沿っており、
**仕様が変われば動作も変わります。** ハードウェアの仕様は
[hra1129/Y8960_Cartridge](https://github.com/hra1129/Y8960_Cartridge) で
開発されています。

## Y8960 の構成

Y8960 は 8 つのブロックでできています。blueMSX+ では一式をカートリッジとして
まとめて挿すほかに、**ブロックごとに独立したデバイス**としてマシン構成に
1 つずつ追加することもできます。

| 表示名 | 内容 |
|---|---|
| Y8960 SCC | SCC、バンクメモリ、I/O イネーブラ、メモリマップド I/O。**カートリッジ ROM はここに載せます** |
| Y8960 OPLLEX | YM2413 相当。チャンネルごとに 4 種類の音色 ROM を切り替えられ、チャンネルごとに定位を置けます |
| Y8960 OPL2EX | YM3812 + ADPCM-B 相当 |
| Y8960 SSGS | YM2149 相当 ×2。チャンネルごとの音量と定位付き |
| Y8960 OPM | YM2151 相当 |
| Y8960 MSX-TIMER | 4 本のカウンタと割り込み |
| Y8960 MSX-MIXER | ブロックごとの音量とマスター音量。メモリマップド I/O の `7FF7h`-`7FFAh`、`7FFDh`、`7FFEh` |
| Y8960 System Controller | カートリッジの識別（I/O `40h`-`42h`）。ソフトが Y8960 を見つけるのに使います |

## カートリッジとして挿す

**一式をまとめて挿すのがいちばん簡単です。** 8 つのブロックが一度に入ります。

- **ROM イメージ無しで挿す** — **ファイル → ROMスロット → 特殊カートリッジ →
  Y8960 Cartridge**
- **ROM イメージを載せて挿す** — **ファイル → ROMスロット** から ROM イメージを
  挿入し、**ROM タイプ** に **Y8960 Cartridge** を選びます。ROM はバンクメモリに
  載ります（ファームウェアを使う場合はこちら）

コマンドラインから挿す例:

```
blueMSX+.exe /machine "<マシン構成名>" /rom1 <ROM ファイル> /romtype1 Y8960
```

カートリッジを抜くと 8 ブロックとも外れます。

**マシン構成にも Y8960 のブロックが入っているマシンで使わないでください。**
同じブロックが二重になり、音量が倍になります。

## マシン構成に追加する

ブロックを選んで載せたいときは、こちらを使います。

**ツール → マシン構成編集** を開き、**メモリ** タブの **追加...** で
上の表のタイプを選びます。**カートリッジの形では** 8 つすべてを追加すると
Y8960 一式になります。

**Y8960 SCC だけは ROM イメージを指定します**（カートリッジ ROM）。
ほかの 7 つは ROM を持ちません。

Y8960 SCC だけをカートリッジとして挿すこともできます。ほかの 7 つを
マシン構成に追加しておき、**ファイル → ROMスロット** から ROM イメージを
挿入して、**ROM タイプ** に **Y8960 SCC** を選びます。
**Y8960 SCC はどちらか一方の方法で 1 つだけ**にしてください。

設定ファイル（`config.ini`）を直接編集する場合、`[Slots]` に書く番号は次のとおりです。

| タイプ | 番号 | コマンドラインでの名前 |
|---|---|---|
| Y8960 OPLLEX | 200 | `Y8960OPLLEX` |
| Y8960 OPL2EX | 201 | `Y8960OPL2EX` |
| Y8960 SSGS | 202 | `Y8960SSGS` |
| Y8960 MSX-TIMER | 203 | `Y8960TIMER` |
| Y8960 MSX-MIXER | 204 | `Y8960MIXER` |
| Y8960 SCC | 205 | `Y8960SCC` |
| Y8960 OPM | 206 | `Y8960OPM` |
| Y8960 System Controller | 208 | `Y8960SYSCTRL` |

一式をまとめて挿すときの **Y8960 Cartridge** は番号 207、コマンドラインでの名前は
`Y8960` です。**こちらはカートリッジ専用で、マシン構成には追加できません。**

v3.1.1-y8960.2 までの版で作った `config.ini` は番号が 180-187 なので、上の表のとおり 20 を足して
書き換え、DCSG（186）の行は消してください。残すと 206 の Y8960 OPM になります。カートリッジの履歴とセーブステートも同じ番号を持つため、
そのまま使えません。

コマンドラインから Y8960 SCC だけをカートリッジとして挿す例:

```
blueMSX+.exe /machine "<マシン構成名>" /rom1 <ROM ファイル> /romtype1 Y8960SCC
```

## I/O とメモリマップド I/O

ブロックの I/O ポートは I/O イネーブラを開くまで応答しません（リセット直後はすべて閉じています）。
イネーブラはメモリマップド I/O にあり、見える条件は「バンクメモリと SCC」の表のとおりです。
メモリマップド I/O の**トンネル**からは、イネーブラを開かなくても各ブロックに書き込めます。

| ブロック | I/O ポート | イネーブラ | トンネル |
|---|---|---|---|
| OPLLEX | `7Ch` アドレス / `7Dh` データ（書き込みのみ） | `7FF6h` bit 0 | `7FF4h` / `7FF5h` |
| OPL2EX | `C0h` アドレス・ステータス / `C1h` データ | `7FFFh` bit 0 | `7FF2h` / `7FF3h` |
| SSGS | `A0h` レジスタ / `A1h` データ / `A2h` 読み出し（2 系統目だけ） | `7FFFh` bit 1 | `7FF0h` / `7FF1h` |
| OPM | `7Eh` アドレス / `7Fh` データ（読むとステータス） | `7FFFh` bit 2 | `7FFBh` / `7FFCh` |
| MSX-TIMER | `B0h`-`B3h` | `7FFFh` bit 7 | なし |
| MSX-MIXER | なし（メモリマップド I/O のみ） | なし | `7FF7h`-`7FFAh`・`7FFDh`（音量）、`7FFEh`（マスター音量） |
| System Controller | `40h`-`42h` | なし（常に応答します） | なし |

**トンネルは書き込みのみです。** 閉じているイネーブラの I/O ポートを読むと `FFh` が返ります。

**`7FFFh`（イネーブラ 2）は読み出せます。** bit 0・1・2・7 は書いた値、bit 3-6 は 0 です。`7FF6h`（イネーブラ 1）は書き込みのみです。

### バンクメモリと SCC

| | |
|---|---|
| バンク | 256KB。`#0`-`#15` が ROM、`#16`-`#31` が RAM |
| RAM への書き込み | RAM モード（`48FBh`）で `#16`-`#31` を出したとき、`6000h`-`BFFFh` に書き込めます。**`4000h`-`5FFFh` には書き込めません** |
| ミラー | `4000h`-`7FFFh` の内容は `C000h`-`FFFFh` にも、`8000h`-`BFFFh` の内容は `0000h`-`3FFFh` にも読み出せます。ミラーには書き込めません |
| SCC | BANK2 のバンクレジスタに `3Fh` を書くと `9800h` に SCC が出ます。RAM モードでは、BANK1 に `3Fh` を書くと `7800h` にも出ます。BANK0 と BANK3 には出ません。チャンネルごとの定位は「SCC」の節 |
| メモリマップド I/O | `7FF0h`-`7FFFh`（`7FFFh` を除いて書き込みのみ。読み出すと BANK1 のバンクの内容が返ります）。RAM モードでは、BANK1 に ROM バンク（`#0`-`#15`）を出しているときだけ見えます。BANK1 に RAM バンク（`#16`-`#31`）を出しているときはその範囲を RAM として書け、SCC を出しているときは SCC のレジスタになります。互換モードでは常に見えます |

## ブロックごとの動作

### OPLLEX

YM2413 と同じレジスタに加えて、**`40h`-`48h`**（チャンネル 0-8）の
bit 1-0 で、そのチャンネルが使う音色 ROM を選びます。

| 値 | 音色 |
|---|---|
| 0 | OPLL（YM2413） |
| 1 | OPLL-X（YM2423） |
| 2 | OPLL-P（YMF281） |
| 3 | VRC7 |

ユーザー音色（音色 0）はチャンネルで共通です。バンクを切り替えても変わりません。

**`50h`-`58h`**（チャンネル 0-8）はステレオの定位です。1 が左端、128 が中央、255 が右端で、
0 は中央と同じです。リセット直後は中央です。リズム音は元のチャンネルの定位に従います
（BD は `56h`、HH と SD は `57h`、TOM と CYM は `58h`）。リズム音は楽音の 2 倍の大きさで混ざります。

プリセット音色は各チップの ROM そのものではなく、互換の音色データです（末尾の「帰属表示」）。
そのため OPLL の音色は、本体の MSX-MUSIC と完全には一致しません。

### OPL2EX

YM3812 のレジスタ配置で、**`E0h`-`F5h` による 4 種類の波形選択**に対応しています
（`01h` の bit 5 で有効になります）。リズム音には波形選択が効きません。

ADPCM-B のサンプル RAM は **256KB** です。

**`F6h`-`FEh`**（チャンネル 1-9）と **`FFh`**（ADPCM）はステレオの定位です。1 が左端、128 が中央、
255 が右端で、0 は中央と同じです。リセット直後は中央です。リズム音は元のチャンネルの定位に従います
（BD は `FCh`、SD と HH は `FDh`、TOM と CYM は `FEh`）。リズム音は楽音の 2 倍の大きさで混ざります。
Y8960 の ADPCM にはサンプル ROM がありません。レジスタ `08h` の bit 0（Y8950 では ROM への切り替え）を
立てると、空の ROM を選んだのと同じになります。サンプル RAM は読むと 0 で、書き込みは届きません。

`07h` の bit 3（SP-OFF）を立てると、再生を続けたまま ADPCM の出力が消えます。

`C1h`（データ）から読み出せるのはレジスタ `0Fh`（ADPCM のデータ）だけで、ほかのレジスタは `FFh` が返ります。
ステータスの bit 0（PCM_BSY）は `07h` の START に従い、一回再生が終わったときと、`07h` に `81h` を書いたときに 0 になります
（Y8950 は 1 のまま残ります）。

MSX-AUDIO のキーボード端子、13bit DAC、I/O ポートは持ちません。

### SSGS

| アドレス | 内容 |
|---|---|
| `00h`-`0Fh` | 1 系統目（YM2149 と同じ配置） |
| `10h`-`1Fh` | 2 系統目（同上） |
| `20h`-`22h` / `24h`-`26h` | 1 系統目 / 2 系統目のチャンネル A/B/C の**音量**。0 で消音、1-127 はリニア（値/128）、bit 7 が立っていれば最大 |
| `28h`-`2Ah` / `2Ch`-`2Eh` | 1 系統目 / 2 系統目のチャンネル A/B/C の**定位**。1 が左端、128 が中央、255 が右端、0 は中央 |
| `23h` `27h` `2Bh` `2Fh` | 未接続 |

**リセット直後は音量 128、定位は中央です。** 両系統とも、トーン周期は `FFFh`、エンベロープ周期は `FFFFh`、
エンベロープの形状（`0Dh` / `1Dh`）は `0Fh` で、そのほかのレジスタは 0 です。定位は両端と中央の値が決まっており、
間はパワーパンニング（中央で左右とも約 0.7 倍）です。

レジスタ番号は下位 6 ビットだけが効きます。`40h` 以上は `00h`-`3Fh` と同じです。

`A2h` から読めるのは 2 系統目のレジスタ（`10h`-`1Fh`、`24h`-`27h`、`2Ch`-`2Fh`）だけです。1 系統目を指しているときは、
MSX 本体の PSG の値が読めます。`17h` の bit 7-6 は `10` で読めます。`27h` と `2Fh` は `FFh` です。

1 系統目の GPIO（`0Eh` / `0Fh`）と 2 系統目のポート B（`1Fh`）には何も繋がっておらず、書いた値を憶えるだけです。
2 系統目のポート A（`1Eh`）はカートリッジの DIP スイッチで、読むと `00h` です。

### SCC

SCC を出しているとき、**`9900h`-`9904h`**（BANK2）と **`7900h`-`7904h`**（RAM モードの BANK1）のチャンネル A-E はステレオの定位です（書き込みのみ）。
どちらも同じ定位のレジスタです。1 が左端、128 が中央、255 が右端で、0 は中央と同じです。リセット直後は中央です。
定位は両端と中央の値が決まっており、間はパワーパンニング（中央で左右とも約 0.7 倍）です。

BANK2 に RAM バンクを出しているときは、`9900h`-`9904h` への書き込みは RAM に入ります。
定位のレジスタを読み出したときの値は決まっていません。`9905h`-`9FFFh` と `7905h`-`7FEFh` は使わないでください。

### OPM

YM2151 と同じレジスタ配置です。クロックは 3.579545MHz です。

`7Fh` を読むとステータスが返ります。bit 1-0 がタイマ B / タイマ A のフラグです。
書き込みはすぐに反映されるので、bit 7（ビジー）は常に 0 です。
タイマの割り込みは MSX の割り込みに入ります（`14h` で有効にしたとき）。
`7Eh` とトンネル（`7FFBh` / `7FFCh`）は書き込みのみです。

左右の出力は各チャンネルの `20h`-`27h` の bit 7-6（R / L）で切り替えます。

### MSX-TIMER

カウンタはカートリッジのシステムクロック 42.95454MHz を数えます。分解能 0-7 の 1 刻みは、0 の 23.8µs から 7 の 390.6ms まで、
1 段ごとに 4 倍です。`B3h` に 0-3 以外を書くと、`B3h` は `FFh` を返します。各カウンタのレジスタ 3 は `00h` です。

### System Controller

I/O `40h`-`4Fh` は MSX の拡張 I/O で、`40h` に書いた ID の装置だけが応答します。Y8960 の ID は `80h` です。

| 操作 | 読み出し |
|---|---|
| `40h` に `80h` を書く | `40h` が `7Fh` |
| 続けて `41h` に `02h`（Y8960 Cartridge）を書く | `41h` が `FDh`。ほかの値では `FFh` |
| 続けて `42h` に `01h`（Config ROM）を書く | `42h` が `FEh`。ほかの値では `FFh` |

Config ROM の読み書き（`43h`-`47h`）はエミュレートしていません。読むと `FFh` で、書き込みは無視されます。

### MSX-MIXER

メモリマップド I/O の `7FF7h`-`7FFAh` と `7FFDh` が、ブロックごとの音量です。
`7FFEh` はマスター音量で、5 つのブロックすべてに掛かります。

| アドレス | 音量 |
|---|---|
| `7FF7h` | SSGS |
| `7FF8h` | OPLLEX |
| `7FF9h` | OPL2EX（ADPCM を含みます） |
| `7FFAh` | SCC |
| `7FFDh` | OPM |
| `7FFEh` | マスター（上の 5 つすべて） |

0 で消音、1-127 はリニア（値/128）、bit 7 が立っていれば最大です。リセット直後はすべて 128（最大）です。
ブロックの音量とマスター音量は掛け合わされます。たとえば両方が 64 なら、そのブロックは 1/4 の大きさになります。
マスター音量は Y8960 の音だけに掛かり、MSX 本体の音源には影響しません。
I/O ポートはありません。Y8960 MSX-MIXER をマシン構成に置かない場合、音量はすべて最大のままです。

音源どうしの大きさの比は、実機のカートリッジ（ハードウェアの v0.9.10）で測った比に合わせてあります。
各音源の 1 チャンネルを最大の音量で鳴らしたとき、OPM に対して SSGS が約 0.9dB、OPL2EX が約 3.0dB、
OPLLEX と SCC が約 3.6dB 小さくなります。

## 音量の調整

**ツール → ミキサー（個体ごと）** に、Y8960 のブロックが「Y8960」の下に 1 行ずつ出ます
（SCC、OPLL、OPL2、SSG、OPM）。行ごとに有効/無効・音量・パンを変えられます。
設定は `bluemsx.ini` に保存され、次に同じ場所に挿したときに戻ります。

テーマのミキサー画面には Y8960 の帯がありません。Y8960 全体の音量・パン・有効/無効を変えるには、
エミュレータを終了してから設定ファイル `bluemsx.ini` を編集します。

```
sound.mixerChannel.MIXER_CHANNEL_Y8960.enable=yes
sound.mixerChannel.MIXER_CHANNEL_Y8960.pan=50
sound.mixerChannel.MIXER_CHANNEL_Y8960.volume=90
```

## ファームウェア

Y8960 を駆動する拡張 BASIC と BIOS が
[madscient/MsxSoundSuiteExtension](https://github.com/madscient/MsxSoundSuiteExtension)
で開発されています。**本エミュレータには同梱していません。**
入手方法と利用条件はそちらを参照してください。

## 動作の確認が済んでいない機能

次の機能は実装されていますが、動作の確認が済んでいません。

- MSX-MIXER の音量とマスター音量が OPLLEX / OPL2EX / SSGS に効くこと（SCC は確認済み）
- OPL2EX の定位を耳で確かめること（コア単体では確認済み）
- OPL2EX の SP-OFF を耳で確かめること（コア単体では確認済み）
- **ツール → マシン構成編集** から Y8960 System Controller を追加すること
- Y8960 SCC を追加しないカートリッジ形のマシンで、ほかのブロックが常に応答すること
- **Y8960 Cartridge** に ROM イメージを載せてファームウェアを動かすこと
- ステートセーブとロード
- ファームウェア（MsxSoundSuiteExtension）での動作
